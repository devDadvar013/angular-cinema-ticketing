# سینماتیکت 🎬

سامانه فروش آنلاین بلیط سینما با **Angular 21** و **Server-Side Rendering (SSR)**.

## امکانات

- فهرست فیلم‌های در حال اکران
- صفحه جزئیات فیلم با سانس‌ها، تاریخ شمسی و قیمت
- انتخاب صندلی (صندلی‌های معمولی و VIP، با صندلی‌های رزروشده)
- سبد خرید و صفحه پرداخت با کد پیگیری
- رابط کاربری فارسی و راست‌چین (RTL)
- رندر سمت سرور (SSR) با prerender صفحه اصلی

## اجرا

```bash
# نصب وابستگی‌ها
npm install

# حالت توسعه
npm start

# ساخت production (همراه با SSR)
npm run build

# اجرای سرور SSR
npm run serve:ssr:cinema-ticketing
```

سرور SSR روی پورت `4000` (قابل تغییر با متغیر `PORT`) اجرا می‌شود.

## ساختار

```
src/app/
  models/      مدل‌های دامنه (فیلم، سانس، صندلی، رزرو)
  data/        داده‌های نمونه
  services/    سرویس سینما و سرویس رزرو
  utils/       ابزارهای قالب‌بندی فارسی و تاریخ شمسی
  components/  کامپوننت کارت فیلم
  pages/       صفحات home، جزئیات فیلم، انتخاب صندلی، پرداخت
```

> توجه: داده‌ها نمونه (mock) هستند و رزروها فقط در حافظه مرورگر نگهداری می‌شوند.
